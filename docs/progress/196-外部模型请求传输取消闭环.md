# 外部模型请求传输取消闭环

> 日期：2026-09-21
> 范围：Reviewer / Outcome Verifier / Vision Worker 的外部模型 HTTP(S) 调用

## 问题

此前三个 Worker 虽持续 Heartbeat，但模型请求由同步 `urllib` 阻塞执行。Lease 丢失只能在响应
返回后拒绝结果，无法停止本地等待和响应传输。Task 取消后，Reviewer、Outcome 和 Challenge
Job 的 Heartbeat 也没有统一校验 Owner Task 是否仍处于对应活动状态。

## 实现

- 新增无代理、无重定向、无 Cookie、无连接池的 `CancellableHttpClient`。每次调用独占一个
  HTTP(S) 连接，并将其绑定到当前 Job 的 `lease_lost` 事件。
- 取消事件到达时对实际 socket 执行 `SHUT_RDWR` 后关闭，使阻塞中的 `getresponse/read` 立即退出；
  正常完成时同步终止监听线程，不遗留每请求后台线程。
- Reviewer、Outcome Verifier、Vision 三条模型调用均传入同一 Lease 事件，并将传输取消归一为
  `MODEL_PROVIDER_REQUEST_CANCELLED`。Loop 对 Lease 丢失统一返回自身稳定错误码，不发送过期
  `complete/fail` 回写。
- Control Plane 的三个 Heartbeat 在续租前重新核对 Owner：Reviewer 仅接受
  `AWAITING_REVIEW/IN_REVIEW`，Outcome 仅接受 `VERIFYING_OUTCOME/IN_REVIEW`，Vision 仅接受
  `WAITING_FOR_HUMAN/ANALYZING`。Task 被取消或状态前进后续租立即 fail-closed，成为传输取消信号。
- Worker 镜像显式包含共享传输模块，Build Gate 同步执行 Python 编译，避免宿主机测试和容器内容
  不一致。

## 验证

- `make test-agent-worker`：41 项通过。
- 真实本地阻塞 HTTP Provider 收到请求后不返回 Header；设置取消事件后，请求线程在 1 秒内退出。
- Reviewer、Outcome、Vision 三种真实 Provider 类均验证 `MODEL_PROVIDER_REQUEST_CANCELLED`。
- Reviewer 与 Outcome Loop 验证 Heartbeat 拒绝会关闭真实 Provider socket，且只发生
  `start → heartbeat`，不发生迟到 `complete/fail`。
- `./gradlew -p apps/control-plane test`：通过。

## 边界

该闭环保证客户端传输、本地等待和结果处理可中途取消，但 TCP/TLS 断开不等于第三方模型已经停止
服务端推理或计费。OpenAI 官方或商业聚合 Provider 若要求服务端强取消，必须单独声明能力、返回可
取消的 Provider Request ID，并通过其 Cancel API 的目标环境 Gate；不支持该能力的 Provider 只能
获得本次实现的传输级取消保证。
