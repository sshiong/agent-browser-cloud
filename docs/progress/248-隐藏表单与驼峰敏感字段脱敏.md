# 隐藏表单与驼峰敏感字段脱敏

> 日期：2026-10-02
> 范围：State Collector、Recording/Screenshot DOM 遮罩和公开 Replay 异常摘要。

## 复现

进度 247 的公开 IdP 失败日志暴露了隐藏防伪字段的值。State 的 DOM 采集原先只将
password 类型、显式分类、敏感 autocomplete 和带单词边界的名称识别为敏感。
hidden 类型未纳入；`__RequestVerificationToken`、`apiKey`、`clientSecret`
等驼峰名称也不能匹配原正则。Recording/Screenshot DOM 遮罩存在同类名称漏检。

在既有真实 Chrome State 测试中加入两个 hidden 字段及两个可见驼峰 Secret 字段，
旧代码在公共 State 序列化包含合成私有值的断言上失败。新增断言放在浏览器与
临时 Profile 清理后执行，失败不会遗留该测试的浏览器。

隔离属性 Fixture 执行三条生产 JavaScript 敏感判定函数，旧代码三条均失败；
实际 `wait_for_named_target` 超时函数的故障注入也确认旧异常摘要包含合成字段值、
URL Query 和标题。这些 Fixture 使用合成值，不包含公开站实际令牌或客户数据。

## 修改

- State 的 hidden 控件一律敏感，名称与 value 不进入公共投影。
- State、Recording、Screenshot 在名称匹配前切分驼峰及首字母缩写边界；既有
  password、OTP、显式分类与 autocomplete 规则保持有效。OTP controlType 同步
  使用该名称规则，`oneTimeCode` 可正确识别为一次性验证码控件。
- 可见 Secret 控件走原有敏感输入约束，普通字段与按钮继续保持原行为。
  hidden 控件不会因此变为可执行 Target；截图仍跳过无面积区域。
- Replay 所有显式 AssertionError 的动态插值统一进入有界元数据摘要。
  只输出固定枚举、已知状态/计数、HTTP 状态和交互布尔值，不输出页面文字、名称、
  value、URL、自由错误文字或 Secret 引用；未知字段和字符串省略，不对 OTP 做 Hash。
  大集合限制八项、递归深度限制五层。成功路径的执行、断言和 Dataset 未放宽。
- 新增实际超时/HTTP 错误故障注入，以及 AST 检查，防止显式断言再次直接插入
  原始响应。该保证限于本 Harness 的显式断言，不宣称任意第三方异常或所有日志已脱敏。

API、Protobuf、数据库、SDK 和授权白名单未修改。本次不声称能够凭名称识别所有
未标注 Secret，也不替代客户视觉数据集与真实环境生产验证。

## 验证
