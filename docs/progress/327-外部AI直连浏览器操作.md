# 外部 AI 直连浏览器操作

2026-11-24

外部 AI 负责读取页面、决定动作并判断是否达到任务目标。控制面收到明确动作后复用现有状态、风险、Capability、并发操作和真人输入优先规则。只有通过现有确定性低风险判定的动作才会直接派发。已有的独立结果验证仍按部署配置运行。

设置中的 Agent 连接可以显式勾选「直接操作网页」。V141 扩展可写的权限值，已有连接和未指定权限的新连接仍采用原默认值。MCP 可选部署增加四个工具：

| 工具 | 用途 |
| --- | --- |
| `browser_snapshot` | 读取连接拥有的环境的页面、元素和状态游标 |
| `browser_navigate` | 使用当前游标打开明确授权的 HTTP(S) URL |
| `browser_act` | 派发一批最多 20 个低风险动作 |
| `browser_get_action_task` | 查看同一环境的任务状态与执行结果 |

SDK 调用者可在既有 `agent-browser/act` 请求体中选择 `executionMode: DIRECT`。
导航单独提交 `navigateUrl` 和空的 `actions` 数组。导航完成后重新读取快照，再提交目标动作。
敏感输入和需要模型审核的操作继续走受控流程。直连的敏感字段在持久化计划前拒绝。控制模式、模型审查和确认要求仍由服务端策略决定。

OpenAPI 现为 271 Operations / 368 Schemas，TypeScript、Python、Go、Java SDK 同步。
