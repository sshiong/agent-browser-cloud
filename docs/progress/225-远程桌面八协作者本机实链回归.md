# 远程桌面八协作者本机实链回归

> 日期：2026-09-27

## 范围与结果

Gateway 已有每 Actor 码率/帧率配额、单上游 RFB Fan-out、有界广播队列、弱网积压后的最新完整基线恢复与逐连接分辨率。本轮补充八个不同 Actor 同时在线的 loopback TCP/WebSocket/RFB 3.8 回归，检验这些机制在上限人数下共同工作。

回归用一个真实 TCP RFB 上游和八个真实 WebSocket/RFB Viewer：第一个 Viewer 限制为 250 Kbps，其余七个为 8 Mbps。所有 Viewer 完成协议握手和初始帧，随后发布 64×64 Raw 帧突发。断言八人均收到最新完整帧、弱网连接记录积压节流、八人仍在线、后续新帧继续送达，且上游 TCP 连接始终只有一个。测试使用独立 Actor ID，避免同 Actor 共享配额混淆隔离结论。

本地 `cargo test --locked --manifest-path apps/browser-node/Cargo.toml -p remote-desktop-gateway` 的 28 项通过；严格 `cargo clippy --locked --manifest-path apps/browser-node/Cargo.toml -p remote-desktop-gateway --all-targets -- -D warnings` 通过。该回归不修改生产代码或公共契约。

## 仍需的 Gate

这是短时 loopback 测试，不代表目标 Linux 八客户端小时级长稳。真实 x11vnc/Chromium、弱网/丢包、多协作者持续输入、内存与帧龄曲线仍需目标环境验收；硬件 Codec/GPU Helper 仍未实现。
