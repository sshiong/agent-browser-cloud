## 1. 阶段总览

```text
Phase 0  合同与工程基础        [2 周]
Phase 1  单机 Browser Runtime  [3 周]
Phase 2  Session Coordinator   [3 周]
Phase 3  Profile/Proxy/State   [4 周]

Phase 6  集群密度/K8s          [4 周]
Phase 7  企业运营能力          [持续]
```

**总计 MVP（Phase 0-4）**：约 16 周
