## 实现

- 总览“最近 Session”和环境列表右侧共用 `SessionLifecycleActions`：CREATED/HIBERNATED
  显示绿色启动，其他非终态显示红色实心方框停止；操作中防重复提交。
- 停止弹出“是否停止运行？”并显示目标名称/Session ID、任务中断和不可重启提示；取消不发请求。
  允许确认停止中断活跃启动/任务 Operation，复用后端既有终止语义。TERMINATING 不可重复提交。
- API 为已有 `POST /api/v1/sessions/{sessionId}:start` 与
  `POST /api/v1/sessions/{sessionId}:terminate`，使用既有 Tenant/RBAC，返回 202 和持久 Operation。
  无新增契约，OpenAPI/四 SDK 仍为 239 Operations / 319 Schemas。
- 环境列表订阅现有 Workspace SSE 自动刷新状态，断线提示可能过期；写操作同步失效总览查询。
  不通过前端模拟“运行成功”。失败显示后端错误与 Request ID。
