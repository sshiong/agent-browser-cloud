## 实现

State Collector 从连续完整采样构建最多四十个 Target 的有界区域窗口。
只有主 Frame 内、同一受信文档、可见、可交互、未遮挡、有效 Bounds 的 Target
可成为稳定候选。稳定 Element ID、Bounds、非敏感值、焦点和勾选等状态必须
连续相同，至少三份样本、两秒窗口，并且 Route/Focus 具有独立静默证据。

页面持续变化超过十五秒后，只标明已证明的稳定 Target 区域；其他 DOM、Canvas、
非交互 Target、未枚举区域始终未知。没有把全页改成 STABLE。主文档、URL、Tab
改变或采样间隔超出既有连续性上限时重建窗口；旧目标消失后不能续用旧窗口。
截断采样、缺失当前 Tab 网络证据、观察不新鲜、未完成文档均不给区域证明。

未知 XHR/Fetch POST 仍计为 SPA 写入。表单提交、SPA mutation、支付/安全、
critical transaction、上传、下载任何一项活动时，区域 readiness 为 false；
没有按请求年龄、站点路径或 Socket.IO 名称免除事务保护。

证据只保存在 Node 的当前完整快照旁，精确绑定 Session、State Version、Target
Revision、State Hash、URL、Active Tab；十秒后、异常未来时间、Region Resync、
Dialog 降级或 Runtime 注销均无法使用旧证明。区域成员/围栏状态进入 opaque
State Hash，增长中的毫秒数和样本数不造成持续 Hash 漂移。Secret 名称/值及其
低熵 Hash 不进入该证据。没有新增公共 API、Protobuf、数据库或 SDK 字段。

## 继续完成的产品闭环

当前证据不是动作 Grant，普通动作、Batch 和独立 Outcome 仍走既有全页门禁。
还需正式 Protobuf/权威 PostgreSQL 状态投影、公共契约/SDK、N/N−1 默认 unknown、
可信风险/Capability 授权、执行前精确状态重验、仅稳定区域的有界动作与独立
Outcome；高风险和敏感输入策略必须由已有授权体系决定。

这里证明的是有界连续完整采样，没有宣称已经覆盖全部 DOM Mutation 事件、
子 Frame 精确 Document 身份、动态区域所有瞬态变化或 V16 Event Watermarks。
这些证据需随完整动作闭环继续补齐。公开十七例连续稳定性、真实外部 OTP/IdP/
支付/客户 SPA、目标 Linux/云/硬件/多 Region、组织及许可证 Gate 仍保留。
