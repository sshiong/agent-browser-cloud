## 3. 快速开始

### 3.1 一键启动（Docker Compose）

```bash
# 启动所有服务
make compose-up

# 或直接使用 docker compose
docker compose up -d
```

### 3.2 分步启动

#### 步骤 1：启动基础设施

```bash
# 启动 PostgreSQL 和 Redis
docker compose up -d postgres redis

# 等待服务就绪
until docker compose exec postgres pg_isready; do sleep 1; done
until docker compose exec redis redis-cli ping; do sleep 1; done
```

#### 步骤 2：运行数据库迁移

```bash
# 使用 Flyway
flyway -url=jdbc:postgresql://localhost:5432/browsercloud \
       -user=browsercloud \
       -password=browsercloud \
       migrate

# 或使用 Gradle
./gradlew -p apps/control-plane flywayMigrate
```

#### 步骤 3：启动 Control Plane

```bash
# 开发模式（仅本地显式允许直连）
PROXY_ALLOW_DIRECT=true ./gradlew -p apps/control-plane bootRun

# 或构建后运行
./gradlew -p apps/control-plane build
java -jar apps/control-plane/build/libs/agent-browser-cloud-0.1.0.jar
```

#### 步骤 4：启动 Browser Node

```bash
# 先启动独立 Storage Helper
mkdir -p /tmp/browsercloud-helpers
STORAGE_HELPER_SOCKET=/tmp/browsercloud-helpers/storage.sock \
PROFILE_STORAGE_ROOT=/tmp/browsercloud-profile-storage \
  cargo run --manifest-path apps/browser-node/Cargo.toml --bin storage-helper &

# 再启动 Node Agent（仅本地显式允许直连；代理模式请同时启动 Network Helper）
ALLOW_DIRECT_NETWORK=true \
STORAGE_HELPER_SOCKET=/tmp/browsercloud-helpers/storage.sock \
PROFILE_STORAGE_ROOT=/tmp/browsercloud-profile-storage \
  cargo run --manifest-path apps/browser-node/Cargo.toml --bin node-agent

# 或构建后运行
cargo build --manifest-path apps/browser-node/Cargo.toml --release
./apps/browser-node/target/release/node-agent
```

#### 步骤 5：启动 Web Console

```bash
cd apps/web-console
pnpm install
pnpm dev
```

### 3.3 验证服务

```bash
# 检查 Control Plane
curl http://localhost:8080/actuator/health

# 检查 Web Console
open http://localhost:3000

# 创建测试 Session
curl -X POST http://localhost:8080/api/v1/sessions \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: test-001" \
  -d '{"tenantId":"test-tenant","profileId":"test-profile"}'
```

## 8. 常见问题

### 8.1 PostgreSQL 连接失败

**问题**：`Connection refused: localhost:5432`

**解决**：
```bash
# 检查 PostgreSQL 是否运行
docker compose ps postgres

# 查看日志
docker compose logs postgres

# 重启
docker compose restart postgres
```

### 8.2 Redis 连接失败

**问题**：`Error: Redis connection refused`

**解决**：
```bash
# 检查 Redis 是否运行
docker compose ps redis

# 测试连接
docker compose exec redis redis-cli ping
```

### 8.3 Chromium 启动失败

**问题**：`Failed to launch browser`

**解决**：
```bash
# 检查 Chromium 路径
which chromium

# 检查依赖
ldd $(which chromium) | grep "not found"

# 安装缺失依赖（Linux）
sudo apt install -y libnss3 libatk-bridge2.0-0 libdrm2 libxkbcommon0 libgbm1
```

### 8.4 构建失败

**问题**：`Build failed`

**解决**：
```bash
# 清理构建缓存
make clean

# 或分别清理
./gradlew -p apps/control-plane clean
cargo clean --manifest-path apps/browser-node/Cargo.toml
pnpm store prune

# 重新构建
make build
```

### 8.5 端口冲突

**问题**：`Port already in use`

**解决**：
```bash
# 查找占用端口的进程
lsof -i :8080

# 杀死进程
kill -9 <PID>

# 或修改端口配置
export SERVER_PORT=8081
```

## 9. Makefile 命令

```makefile
.PHONY: build test lint fmt compose-up compose-down clean contracts contracts-check test-integration

# 构建所有组件
build:
	./gradlew -p apps/control-plane build
	cargo build --locked --workspace --manifest-path apps/browser-node/Cargo.toml
	pnpm --dir apps/web-console build

# 运行所有测试
test:
	./gradlew -p apps/control-plane test
	cargo test --locked --workspace --manifest-path apps/browser-node/Cargo.toml
	pnpm --dir apps/web-console test

# 代码检查
lint:
	./gradlew -p apps/control-plane check
	cargo fmt --all --check --manifest-path apps/browser-node/Cargo.toml
	cargo clippy --locked --workspace --all-targets --manifest-path apps/browser-node/Cargo.toml -- -D warnings
	pnpm --dir apps/web-console lint
	pnpm --dir apps/web-console format:check

# 启动本地服务
compose-up:
	docker compose up -d --build

# 停止本地服务
compose-down:
	docker compose down

# 清理构建产物
clean:
	./gradlew -p apps/control-plane clean
	cargo clean --manifest-path apps/browser-node/Cargo.toml
	pnpm --dir apps/web-console clean

# 格式化代码
fmt:
	./gradlew -p apps/control-plane spotlessApply
	cargo fmt --all --manifest-path apps/browser-node/Cargo.toml
	pnpm --dir apps/web-console format

# 生成 Contract
contracts:
	cd packages/contracts && buf lint
	cd packages/contracts && buf generate

# 契约校验
contracts-check:
	cd packages/contracts && buf lint
	pnpm --package=@redocly/cli@1.34.0 dlx redocly lint packages/contracts/openapi/session-api.yaml
	python3 -m json.tool packages/contracts/json-schema/error-envelope.json >/dev/null

# 真实进程集成烟雾测试
test-integration:
	./tests/integration/smoke.sh

# 运行数据库迁移
migrate:
	./gradlew -p apps/control-plane flywayMigrate

# 查看迁移状态
migrate-info:
	./gradlew -p apps/control-plane flywayInfo
```

### A. 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| DATABASE_URL | jdbc:postgresql://localhost:5432/browsercloud | PostgreSQL 连接 |
| REDIS_HOST | localhost | Redis 主机 |
| REDIS_PORT | 6379 | Redis 端口 |
| SERVER_PORT | 8080 | Control Plane 端口 |
| LOG_LEVEL | INFO | 日志级别 |
| CHROMIUM_PATH | chromium | Chromium 路径 |
| NODE_AGENT_PORT | 9090 | Node Agent 端口 |
| RUNTIME_ROOT | /tmp/browsercloud-runtime | Node Runtime 工作目录 |
| NETWORK_HELPER_SOCKET | 空 | 独立 Network Helper 的绝对 Unix Socket 路径；生产必填 |
| NETWORK_HELPER_TIMEOUT_MS | 5000 | 单次 Helper IPC 超时 |
| STORAGE_HELPER_SOCKET | 空 | 独立 Storage Helper 的绝对 Unix Socket 路径；生产必填 |
| STORAGE_HELPER_TIMEOUT_MS | 30000 | 单次 Checkpoint/Restore IPC 超时 |
| PROFILE_STORAGE_ROOT | `/tmp/browsercloud-runtime/profile-storage` | Node 路径校验与 Storage Helper Profile 根目录；两侧必须一致 |
