# 采样中断后的页面静默证据重建与 CI 核验

> 日期：2026-10-03
> 基线：`dbd06e455019f2930d74bc7280b06dc0002c3f4d`
> 范围：State Collector 的连续采样证据，不新增稳定区域动作或公开状态。

## 缺陷与修复

原 `update_page_stability` 只比较前后 DOM/Layout/Focus/Route 指纹，并把两次
采样之间的全部时间加到 quiet。观察线程长时间没有采样时，相同端点并不能
证明空档内页面持续不变。旧生产函数运行新增回归，三十秒空档与原两秒窗口
被累计为三十二秒，且 `evidence_fresh=true`；该回归实际失败。

更新逻辑要求采样间隔在有界连续性上限内。基础上限十秒，与公开 FRESH 年龄
相同；显式低预算的正常慢采样允许配置间隔加两秒，取二者较大值。现有预算
范围 10%—100%，100%/25% 间隔分别为二/八秒、上限十秒，10% 间隔二十秒、
上限二十二秒。生产 collect 调用根据当前 Session 配置取得这个上限，采样
节奏和资源预算没有变化。

超限或记录时间晚于当前单调时间时，四类窗口全部归零、证据降级；更新当前
指纹及采样时间后，下一次及时采样从新窗口累计。初次样本维持零 quiet。
既有网络、当前文档、State/Target/Tab、实体和风险校验保持原语义。这里依然
是有界采样证据，不声称能观察两个正常样本之间的每次变化。

- 新回归验证空档降级、hash bucket 清零、后续新窗口、正常八秒间隔、显式
  二十秒慢采样和异常未来时间；原预算测试验证生产上限计算及预算清理。
- 最终代码 Rust Workspace **198 passed / 0 failed / 7 ignored**；其中四项
 真实 Chrome 测试另外显式运行，**4 passed / 0 failed**。
- `cargo +1.99.0 clippy --workspace --all-targets -- -D warnings` 成功。
