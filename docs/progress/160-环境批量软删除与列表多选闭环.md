# 环境批量软删除与列表多选闭环

> 日期：2026-09-02  
> 状态：仓库内实现、本机真实运行与完整 Integration 验收已通过；GitHub Workflow 待推送后验证。

## 问题与边界

环境列表原先只能逐行打开详情或三点菜单，没有左侧复选框，也没有可审计的
批量删除契约。本切片仅实现多选删除；复制、导出仍为后续功能。删除采用证据保留的
软删除，不得连带清除 Audit、Recording 或 Recovery 记录。

## 实现

- V113 为 `sessions` 增加 `deleted_at` / `deleted_by` / `deletion_batch_id`、一致性约束和有界索引。
  JPA 与所有常规 Session 列表、搜索、路由和 Overview 查询隐藏已删行；物理记录仍作为
  审计、录制与恢复证据存在。
- 新增 `POST /api/v1/sessions:batch-delete`，最多 100 条，要求 `OPERATE` RBAC、Tenant
  隔离和幂等键。服务端先锁定全批，只允许 CREATED/TERMINATED 且无 ACTIVE
  Operation 的 Session；任一条不满足时返回冲突，整批不变。
- 成功删除在同一事务中写入每 Session 追加式 `DELETE` Audit，并释放
  `coordinator_session_routes` 与 `coordinator_ownership`，防止 Scheduler 后续处理已隐藏
  Session。同一幂等键只能重放精确相同的 Session 集合。
- Web/Tauri 共用的环境列表增加左侧复选框、当前页全选、已选计数、清除和
  确认对话框。不可删状态直接禁用选择，请求期间防重入，成功后失效 Session 和
  Workspace Overview 查询。
- OpenAPI 和 TypeScript/Python/Go/Java 四 SDK 已同步，公开基线为
  239 Operations / 319 Schemas。
