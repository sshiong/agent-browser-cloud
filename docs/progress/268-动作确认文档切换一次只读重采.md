## 发现与修复

progress 267 的真实公开 LOGIN 回放在 Selenium 表单提交的 `CLICK_TARGET` Task
失败，Node 记录 `CDP document changed during snapshot`。该类型化错误由 Node
比较采集前后的 CDP 主 Frame/Loader 产生；拒绝混合文档快照是正确行为，但既有动作
确认的一次重采只包含超时和关闭连接，没有覆盖这个导航收尾情形。

动作确认现在对 Node 类型化 `DOCUMENT_CHANGED` 延迟原有 100 毫秒，再读取一次
当前活动页面。重采不重新发送点击、文本或其他输入，不恢复旧 Target，不合并前后
两份文档。只有第二份快照自己通过完整身份检查后才返回；两次都变更则仍失败。

`DOCUMENT_IDENTITY_UNAVAILABLE` 与页面/协议错误文本伪造的同名字符串不获得新增
重采。普通周期采集、Region Resync、导航快照保持原有拒绝路径，既有重采次数、
单次读取预算、Operation/Epoch、域名和独立 Outcome 验证保持有效。读取成功不是
业务成功，后续仍需原正式验证。

## 剩余边界

只修复输入后遇到精确文档变化的读取收尾；不把未知网络写入视为完成，也不自动重发
可能已生效的动作。公开十七例连续稳定性、计划到授权前版本过期、子 Frame 身份、
稳定区域完整风险授权/Event Watermarks/动作/独立 Outcome 和十一项外部 Gate 继续保留。
