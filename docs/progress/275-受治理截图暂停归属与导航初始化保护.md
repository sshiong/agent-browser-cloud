## 独立复现的缺口

旧 Screenshot 在安装、验证 DOM 敏感遮罩后，以 Emulation.setScriptExecutionDisabled
冻结脚本。该窗口若发生导航，新页面的初始化脚本可能被跳过；重新启用脚本不会重放
它们。Node 对普通 Agent Action 及导航也会按采样策略捕获 Evidence，因此这条路径
并非仅用于手工截图。

自有 loopback HTML/Chrome 对照：正常导航的 root child count 为 1，禁用脚本期间
导航后再恢复仍为 0；调试器暂停方案恢复为 1、页面保持 visible。生命周期冻结也能
恢复初始化，但令活动页 hidden 且恢复后仍 hidden，未用于本次截图方案。
连续 Recording 的 screencast/privacy scanner 路径没有使用上述脚本禁用命令。

真实回归通过 loopback CDP 代理，在生产捕获执行到冻结后的 DOM 读取时，使用第二个
CDP 连接导航到自有页面。实际旧 4902ded 捕获路径编译成功，并在“新页面初始化必须
保留”的断言处失败，观测 mounted=false；新路径拒绝跨文档像素并保留 mounted=true。
旧版本测试仅补入同一测试模块及 Socket 类型别名，不修改其生产捕获实现。

progress 274 的公开全量空白页仍没有与该冻结窗口对齐的原始证据；本次复现证明代码
缺口，不追溯认定那轮公开站失败原因。

## 实现与保护

- 每个注册 Session 使用独立截图锁；所有自动 Evidence 和正式 Screenshot 共用。
  捕获与清理的有界任务持有 socket/锁，即使上层 future 被取消，仍执行清理；
  取消的接收者不能启动对象提交，下一次截图须等前次清理结束。
- 先启用本连接的 Debugger，拒绝已有暂停；不设置 breakpoint、异常暂停或页面生命周期
  策略。固定 debugger 语句带随机 sourceURL，必须收到匹配 scriptParsed/scriptId、
  顶层 callFrame、other reason 和空 hitBreakpoints 的暂停证明才允许捕获。
  外部暂停、未证明暂停或捕获中恢复均拒绝。
- 捕获前、安装遮罩后、暂停后和像素读取后复核精确主 Frame/Loader；缺失、异常或
  改变均拒绝返回像素。暂停下继续重验 DOM root 与遮罩数量，保留 JPEG/尺寸预算、
  Capture Mode/Clip、原 Actor/State/Tab 和 Storage Helper 提交围栏。
- 清理先取固定无副作用的 Renderer 回应，读取排队的暂停/恢复事件；仅恢复本连接
  已证明的暂停，随后 disable 本连接 Debugger、移除遮罩、关闭 socket。
  恢复或清理未确认时丢弃已捕获像素。每次命令/等待保持五秒有界预算，事件不能续期。
- 夹具以相同事件关系模拟 scriptParsed/paused 和恢复后的延迟 Runtime 回应。
  新增真实夹具 socket 测试；未通过夹具结果替代实际 Chrome。
