# 远程桌面参与者历史分页与保留治理闭环

> 日期：2026-08-12
> 状态：代码、正式契约、四语言 SDK 和真实 PostgreSQL Integration 已完成；GitHub CI 待本轮提交后观察。

## 目标

在不改变“普通 VNC 与 Agent 协作并存”语义的前提下，为远程桌面终态参与者
提供真实、可分页、可保留治理的历史视图。历史数据只来自 Browser Node 权威事件和
PostgreSQL，前端不使用 Mock、localStorage 或定时器伪造连接记录。

## 已完成

- 新增 `GET /api/v1/sessions/{sessionId}/desktop-participants/history`，只返回
  `REVOKED/DISCONNECTED` 终态连接，与既有当前 Context Epoch 在线列表分离；
- 分页使用绑定 Session 的 Base64URL Keyset Cursor，按
  `(observed_at, connection_id) DESC` 稳定续读，单页最多 50 条；损坏游标和
  跨 Session 重放统一返回 `400 INVALID_REMOTE_DESKTOP_PARTICIPANT_CURSOR`；
- V090 以非事务 `CREATE INDEX CONCURRENTLY` 增加终态保留索引，不锁住在线投影；
- 新增默认 30 天的可配置保留任务，每批最多清理 10,000 条；SQL 只能删除
  `REVOKED/DISCONNECTED`，不会删除 `CONNECTED/REVOKE_REQUESTED`；
- Web/Tauri 共用远程桌面页新增“最近连接历史”，展示 Actor、显式状态、时间和
  断开/撤销原因，支持失败重试和按需加载更多；Session SSE 参与者事件会同时失效
  在线与历史查询；
- OpenAPI 和 TypeScript/Python/Go/Java SDK 已更新为 197 个 Operation、263 个
  Schema；前端不直接查库，SDK 与 API Client 可复用到未来桌面端。

## 已验证

- Control Plane 全量 Test/Check、Web 70 项测试、Lint/Build、契约校验和四语言 SDK
  运行时/发布包门禁已通过；
- Repository 单测覆盖 Cursor 往返、跨 Session 拒绝和有界终态清理 SQL；
- `make test-integration` 从空库顺序执行 90 个迁移，以 21 条终态记录验证
  `20 + 1` 两页续读、总数、有无下一页、非终态隔离、跨 Session Cursor 400 和
  V090 索引；原有双 Node/Coordinator/迁移/恢复/审计链同时通过，
  `public_tables=106`、`health=UP`、`audit_chain_valid=true`。
