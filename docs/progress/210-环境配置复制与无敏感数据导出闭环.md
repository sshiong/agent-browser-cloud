# 环境配置复制与无敏感数据导出闭环

> 日期：2026-09-23
> 状态：仓库级闭环；不等于复制运行中的浏览器或登录状态

## 完成内容

- 新增 `POST /api/v1/sessions/{sessionId}:export-configuration`，导出可直接进入现有
  Environment Import 预检/执行链的 schema-v1 JSON，并以规范化内容 Hash 绑定 Manifest 与审计。
- 新增 `POST /api/v1/sessions/{sessionId}:clone`，复用正式 Session 创建服务及其幂等、RBAC、
  Tenant、Group/Tag、Proxy、资源策略和 Browser Identity 校验，不另建旁路创建逻辑。
- Web/Tauri 共用环境三点菜单现提供重命名、复制和导出；复制对话框明确展示 Profile 语义，导出
  生成 `.environment.json` 文件并对失败显式反馈。
- 导出的治理配置包含名称/说明、Profile 引用、Runtime Build、Application Recovery Binding、
  Group/Tags、Region、Proxy Binding Profile、AUTO Resource Policy、Demand、Human Takeover、
  Agent Policy、Extensions 和锁定的 Browser Identity Spec。
- 导出固定排除浏览器运行状态、Cookie/站点存储、Profile Checkpoint 字节、Proxy Credential、
  Agent Secret、Recording/Screenshot、Operation 与执行历史；公共 API 不泄露对象路径或密钥。

## Profile 语义

- `NEW_EMPTY_PROFILE` 是 Web 默认值：创建独立 Profile，只复制环境配置，不复制 Cookie、登录态或
  Checkpoint；Profile 名称使用“复制后环境名 + Profile”，便于审计与运维识别。
- `REUSE_SOURCE_PROFILE` 必须显式选择：新环境引用源 Profile，仍不克隆运行时或历史。并发写入、
  Checkpoint 与 Session Health 继续受既有 Profile Writer、Epoch 和恢复栅栏治理。
- Profile 内容迁移仍使用独立、用途绑定的 Checkpoint 导入/导出流程，不能借环境配置导出绕过。

## 保留边界

- 此能力复制的是受治理配置，不是活动 Chromium 进程、当前页面、任务、操作历史或录像。
- `NEW_EMPTY_PROFILE` 不保证登录态；`REUSE_SOURCE_PROFILE` 也不保证网站 Session 未过期或未撤销。
- 目标云 IdP/KMS/IAM、多 Region、客户站点 Replay、Linux 长稳和组织发布审批仍是独立生产 Gate。
