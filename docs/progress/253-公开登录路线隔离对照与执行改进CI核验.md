## 隔离对照

[249](249-SSE通道注册与Replay订阅竞态修复.md) 的完整 Agent 矩阵在错误密码
提交后的 alert 等待失败，最后 State 已 STALE；独立 CDP 在清理附近看到 Document
POST 约 45 秒后失败，原因尚未定位。

本轮按现有 Dataset 的 `public-expandtesting-login-invalid-password` Case 校验
测试范围，用两个全新隔离 Headless Chrome Profile，分别直连和经过仓库现有
allowlist-forward-proxy 提交一次合成错误密码。代理仅允许精确练习站 Host，
CDP 诊断只输出枚举、HTTP 状态、时间和布尔结果，不输出正文、Cookie、凭据或 URL。
实验没有运行 Agent、State Collector 或 Recorder，不计入平台 Replay Gate。

首版没有验证滚动后的实际点击命中，没有取得表单 POST 证据；代理路线还遇到
CDP 响应超时。该轮不算通过，不能用于路线优劣判断。校准版增加即时滚动、
视口/实际命中检查、明确阶段及重定向前请求记录，随后取得：

| 指标 | 直连 | 测试代理 |
| --- | --- | --- |
| 登录入口 Document GET 200 完成 | 0.880 秒 | 7.311 秒 |
| 练习站 Document POST 302 | 0.363 秒 | 4.046 秒 |
| 返回登录页 Document GET 200 完成 | 0.334 秒 | 3.980 秒 |
| 从点击到明确错误密码 alert | 1.491 秒 | 9.590 秒 |
| `negativeLoginVerified` | true | true |

记录中的 POST 路由为 `OTHER`，没有保存原路径或精确 Frame/Loader。
诊断字段 `mainDocumentPostObserved=false` 的判定仅匹配 `/login`，不覆盖该提交
路由，不能把它当成主 Frame 身份证明；上述结论来自请求记录和精确错误提示布尔值。
本轮不为早期失败的 POST 追溯认定身份，也不据此修改任何产品状态或请求围栏。

结果说明这次隔离流程能完成，未重现先前停滞。单次、不同 Profile 与网络路线
不足以将差异归因于代理，亦不能证明平台的完整 17 例连续运行或小时级长稳。
两条路线结束时仍分别有一个约 0.18 秒的 Socket.IO GET/XHR，没有把它们标记完成。

证据目录：`/tmp/agentbrowser-practice-route-comparison._ottoqae/`（首版）与
`/tmp/agentbrowser-practice-route-comparison.td2wc2se/`（校准版）。目录为 0700，
`evidence.jsonl` 为 0600；自有 Chrome/Proxy 进程已结束，临时 Profile 已删除，
保留两轮原始枚举记录。临时诊断脚本为
`/tmp/agentbrowser-practice-route-comparison.py`，SHA-256 为
`76e3847ef929c67200eececaf7e26bdc5b0740b60dc7576ed4f778a3b3c12591`；
该临时实验不是仓库正式 Agent Gate。
