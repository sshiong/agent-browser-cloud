## 修复及边界

- `prepareLegacyStart` 仅允许未运行旧记录（runtimeBuild/node 均 null、generation/epoch=0、
  CREATED/TERMINATED）在启动事务内补齐元数据，并锁定 Session；不做全库无条件补写。
- 缺 Demand 使用已保存资源级别、扩展和真人协作设置，以及创建默认1个 Tab/0 Agent频率，
  不猜测媒体工作负载。既有 Demand 不覆盖；同租户 Profile 缺失时用原 ID 初始化，已有内容不变。
  已运行/现代环境损坏仍 fail-closed，跨租户数据拒绝。修复及 START 共用事务，失败一起回滚，
  写入 `LEGACY_START_METADATA_REPAIR` 审计，不通过删除或重建 Session 绕过问题。
- 长错误移到可展开浮层，不参与表格列宽；显示实际 reason 与 Request ID；常见资源错误中文说明。
  状态 Badge 和状态点不收缩，文字不换行。Web/Tauri 使用相同组件。
- 未修改公开 API/数据库 Schema；OpenAPI/四 SDK 仍为240 Operations /319 Schemas。
