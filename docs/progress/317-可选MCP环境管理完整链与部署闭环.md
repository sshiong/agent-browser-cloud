# 可选 MCP 环境管理完整链与部署闭环

> 日期：2026-11-10；基线b2f8ea9；首版代码及本机验收通过，当前提交CI待核验。

新增V140、独立连接Bearer认证链、管理员管理API和Agent专用API；随机256bit凭据一次性
返回、PG只保存SHA256，普通API不接受此凭据。每次请求检查有效期/撤销/工具白名单。
管理操作写审计且不含凭据。创建、列表、详情、启停、删除与Operation都限制环境归属。

运行配额从正式sessions状态UPDATE触发：STARTING/RUNNING/RECOVERING等保留名额，
停止过渡不释放，HIBERNATED/TERMINATED/删除才释放，FAILED保留不确定名额。
因此Web/SDK也不能绕过连接配额。启动/停止复用Coordinator路由；删除复用正式软删除。
V140只增列/表内约束/触发器；不删旧数据，回退保留记录，lock_timeout5s。

Gateway采用官方Python MCP SDK1.30.0，固定依赖锁，stateless Streamable HTTP与
结构化返回，提供8个首版环境管理工具。默认loopback，校验Origin/Host，固定上游禁止
工具参数指定代理目标，远程入口需HTTPS。静态Bearer客户端配置不冒充OAuth兼容。
Compose profile mcp默认关闭，Kubernetes optional/mcp不进入默认base。
Web/Tauri设置页可创建连接、调整两类配额、选择工具、撤销并复制一次性连接配置。
