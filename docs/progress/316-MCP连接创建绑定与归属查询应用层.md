# MCP 连接创建绑定与归属查询应用层

> 日期：2026-11-10
> 基线：c7d8b20
> 状态：内部应用层与真实PG测试通过；对外API/MCP尚未开放。

新增AgentConnectionEnvironmentApplicationService：创建/撤销连接、按主体与Tenant
检查有效连接、查询额度；事务内预留环境额度→调用既有SessionApplicationService.create
→JPA flush→JDBC绑定Session归属。预留与创建沿用同一Spring事务，不新造浏览器生命周期。
MCP创建幂等键使用连接命名空间；请求指纹按JSON属性/Map键排序，同键异体拒绝，精确
重放直接返回已绑定Session ID，不重复调用创建。默认不赋予platformAdmin。

详情和有界分页只查该连接未删除的归属记录，再读取正式Session服务；其他主体/租户或
连接外Session拒绝。撤销后拒绝包括读额度在内的访问。没有新增匿名端点、调用者身份
请求头或Gateway放行开关；管理端角色、审计和完整认证将在开放API前接入。

真实PG Gate新增2项应用测试，与原31项共33项无失败/错误/跳过。核验绑定外键、
精确重放只调用创建一次、同键异体、主体/租户隔离、连接外详情拒绝、分页及创建异常
后预留和Session写入共同回滚、撤销拒绝。测试中的SessionApplicationService及
EntityManager为mock，Session行由mock回调写真实PG；因此不宣称完整生产JPA创建、
HTTP或真实MCP客户端链通过。下一阶段需正式服务集成补充该证据。

常规Java回归通过。扩展查询断言初次编译遇AssertJ泛型推断歧义，改为明确局部变量后
常规回归和完整33项PG重跑通过。专用PG容器及匿名卷退出清理，核对残留0，其他容器
保留。公开API仍255 Operations/358 Schemas，本轮不引入契约漂移。

剩余：启动/停止/删除和名额权威收敛、连接管理角色与审计、OpenAPI/SDK、Gateway、
管理UI、可选部署及真实客户端。原有其他目标按用户要求暂让位MCP主线，不声明完成。
