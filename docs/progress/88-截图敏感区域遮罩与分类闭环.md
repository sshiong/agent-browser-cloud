# 截图敏感区域遮罩与分类闭环

> 完成日期：2026-07-31
> 状态：Agent/Observer 截图统一遮罩、页面抗篡改、失败关闭、PostgreSQL 元数据、
> API/Web/Tauri 展示和 N/N−1 兼容已闭环

## 关闭的缺口

进度 72 和 87 已分别完成 Agent 自动截图、Observer 手动截图及 Purpose-bound 访问，
但原始像素在进入 Storage Helper 前没有统一的敏感区域保护。本轮完成：

1. Agent Navigate/Action 与 Observer Manual 继续共用 `SessionEvidenceRegistry`，所有
   JPEG 在 Browser Node 内、写入 Session Ephemeral 路径前执行同一套遮罩；
2. Browser Node 通过受信 CDP `Runtime.evaluate` 创建最高层级、不可交互、不透明遮罩，
   覆盖密码、OTP、支付卡、账户、Secret/Token/Key、SSN 等语义字段，以及
   `data-sensitive/private/redact`、`data-classification` 和跨域 `iframe`；
3. 分类会遍历开放 Shadow DOM，最多扫描 10,000 个 Element。超限、注入失败或返回值
   缺失时不截图、不提交对象；
4. 注入后先校验遮罩数量，再调用
   `Emulation.setScriptExecutionDisabled(true)` 暂停页面脚本；暂停后通过 CDP DOM 域
   独立确认遮罩 Root 和 Region 数量，防止不受信页面在截图瞬间移除遮罩；
5. 截图完成或失败后恢复页面脚本并清理遮罩。恢复/清理失败同样不提交对象，事件记录
   `SENSITIVE_REDACTION_FAILED + FAILED_CLOSED`；
6. State Collector 的 `sensitive` 分类同步扩展到相同的 Password/OTP/Payment/
   Account/Secret/PII 语义与显式 Data Classification，敏感 Target 名称继续不进入
   Control Plane；
7. Node Capability 新增
   `evidenceRedaction=dom-overlay-script-freeze-v1`，没有 Object Storage/Evidence
   数据面时声明 `unavailable`。

这里采用不透明遮罩而不是仅做模糊。模糊仍可能泄露字符长度或高对比轮廓，不透明覆盖
是更强的默认策略。

## 数据与兼容

V063 对 `session_evidence` 追加：

- `redaction_state`：
  `MASKED / NOT_REQUIRED / FAILED_CLOSED / LEGACY_UNVERIFIED`；
- `redacted_region_count`：截图前由 Node 校验的视口遮罩区域数量；
- Result、Redaction State 和 Count 的数据库一致性约束。

Proto `SessionEvidenceCapturedEvent` 追加 Field 14/15。N−1 Node 不发送新字段时，
新 Control Plane 持久化为 `LEGACY_UNVERIFIED`，不会把旧截图伪装成已遮罩；新 Node
提交的 `MASKED` 必须至少有一个 Region，`NOT_REQUIRED` 必须为零，失败必须为
`FAILED_CLOSED`。

公开 Evidence API 不返回 Object Key，只增加 Redaction State/Count。Session Detail
明确显示“已遮罩 N 个敏感区域”“未检测到敏感区域”或“旧版证据：遮罩状态未验证”，
Web 与 Tauri 继续复用同一组件和类型。

## 安全顺序

```text
CDP install opaque masks
→ Runtime result validation
→ Runtime mask-count verification
→ disable page scripts
→ CDP DOM root/count verification
→ Page.captureScreenshot
→ enable page scripts
→ remove masks
→ bounded JPEG validation
→ Ephemeral write
→ Storage Helper commit-last
→ SessionEvidenceCaptured(MASKED / NOT_REQUIRED)
```

任一步失败都不会生成可访问对象。短期签名访问、Purpose Grant、同操作者一次性 Redeem
和 HumanTakeover 阻断继续沿用进度 87 的治理边界。
