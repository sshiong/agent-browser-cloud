# 全局搜索正式闭环

> 日期：2026-07-30
> 状态：仓库内正式闭环；跨 Region 搜索聚合和目标规模长稳待完成

## 本轮目标

关闭 Web Console 顶部长期禁用的“全局搜索”占位，建立可由 Web 与 Tauri 2
共用的真实搜索闭环：

- 所有结果来自正式 Control Plane API 和 PostgreSQL；
- Session、Profile、Group、Tag 严格按认证 Tenant 隔离；
- Runtime 延续既有 READ 可见性，Browser Node 只对管理员身份返回；
- 不索引 Secret、浏览器正文、Cookie、表单值或任意 Session Metadata；
- 查询必须有长度、类型、结果数量和数据库执行成本边界。

## 已完成

### 1. 正式搜索契约与 RBAC

- 新增 `GET /api/v1/search`，支持：
  - `q`：2—128 字符；
  - `types`：`SESSION / PROFILE / GROUP / TAG / RUNTIME / NODE`；
  - `limit`：1—50，默认 24；
- 返回统一 `GlobalSearchResult`：资源类型、ID、标题、非敏感描述、状态、Region 和
  更新时间；
- Controller 使用统一 `PlatformIdentity`，不接受客户端提交 Tenant：
  - Session/Profile/Group/Tag 查询始终带当前 `tenantId`；
  - Node 结果对 Viewer/Operator 直接省略，只有 Tenant Admin、Security Admin 或
    Platform Admin 才会查询；
- 所有来源最多读取 `limit + 1` 条，再按精确匹配、前缀匹配、包含匹配和更新时间
  排序；超过边界返回 `truncated=true`，不做无界聚合。
- `%`、`_` 和反斜杠按普通搜索字符处理，不能借 SQL LIKE 通配符退化为“返回全部”
  或诱发无意义扫描。

### 2. V061 PostgreSQL 有界索引

- 启用 PostgreSQL `pg_trgm`，以非事务 Flyway Migration 和
  `CREATE INDEX CONCURRENTLY IF NOT EXISTS` 为 Session、Profile、Group、Tag、
  Runtime Build 和 Browser Node 建立 GIN Trigram 搜索索引，避免升级时长时间阻塞
  业务写入；
- Flyway 使用 Session-level Advisory Lock 和独立数据库连接执行在线 Schema 变更：
  前者避免 Transactional Advisory Lock 与 `CREATE INDEX CONCURRENTLY` 自身形成等待，
  后者不继承应用 Hikari 连接池面向 API 请求设置的 5 秒 Socket Timeout；
- Repository 查询表达式与索引表达式一致，包含匹配不依赖全表内存过滤；
- Session 搜索从原先扫描完整 Metadata JSON 改为只索引：
  - Session ID；
  - Profile ID；
  - Region；
  - Resource Class；
  - State；
  - 治理字段 `metadata.displayName`；
- 任意 Metadata、浏览器 Current State、网页正文、Secret Ref 正文和用户输入均不进入
  搜索索引。

### 3. Web/Tauri 共用命令面板

- 顶部搜索按钮从 Disabled 占位改为真实 `GlobalSearchDialog`；
- 支持 `⌘K / Ctrl+K`、自动聚焦、ESC 关闭、Tab/Enter 键盘访问和类型过滤；
- 220ms 输入防抖，React Query 使用真实 AbortSignal 取消过期请求；
- 结果按资源类型分段展示，明确 ID、状态、Region 和 Tenant Scoped 边界；
- Session 直接进入详情页，其他资源进入对应正式管理区；
- 加载、空结果、截断、离线/API 失败和 Request ID 均有明确状态；
- Node 类型对无管理员权限的身份不显示，服务端仍独立执行相同 RBAC；
- 组件位于共享 React UI 内，Tauri 不维护另一套搜索状态或 API。

## 真实验收

已通过：

- Control Plane Spotless 与全部 Java 测试；
- `GlobalSearchApplicationServiceTest`：
  - 当前 Tenant 参数传递；
  - 只查询用户选择的资源类型；
  - 精确匹配优先；
  - `limit + 1` 与 `truncated`；
  - 非管理员不查询 Node；
  - SQL LIKE 通配符按普通字符转义；
- Web production build、55 项 Vitest、ESLint、Prettier；
- Tauri 2 Rust 单元测试；
- OpenAPI/Buf 契约检查；
- V061 PostgreSQL 空库 Flyway 迁移；
- 真实 Web Console Playwright：
  - 创建真实 Session；
  - 通过 `/api/v1/search` 搜索名称；
  - 校验返回真实 Session ID 和标题；
  - 从结果进入 Session Detail；
  - Viewer RBAC 全流程继续通过。
