# 直连全量浏览器操控、屏外自动滚动与自定义下拉选择闭环

2026-11-24

针对「下拉框不点击不显示选项」「长页面屏外目标（`OUTSIDE_VIEWPORT`）难以直接操作」以及「直连模式下允许 Agent 自主输入密码/登录框与完成完整浏览器操控（同时严格维持宿主机与沙箱隔离）」的需求，完成 Browser Node、Control Plane、MCP Gateway 与 Web Console 四层贯通修复。

## 变更内容

1. **屏外元素自动可见与自动滚动入视口（`OUTSIDE_VIEWPORT` 不再卡死 Agent）**
   - `apps/browser-node/crates/state-collector/src/lib.rs`：新增 `resolve_target_for_action()` 与 `scroll_path_into_view()`——已可见目标零额外开销直接返回；仅处于当前视口外（`visibility_reason == "OUTSIDE_VIEWPORT"` 且未遮挡、非 `display:none`/`opacity:0` 真隐藏）的目标，先通过 CDP 对精确路径执行 `scrollIntoView({ block: 'center', inline: 'nearest', behavior: 'instant' })`，重采权威状态与坐标，若被吸顶顶栏遮挡则自动上推 120px 复验一次再执行。
   - `apps/browser-node/crates/node-agent/src/main.rs`：普通目标动作、高级指针/按键/触控动作与拖动终点统一改用 `resolve_target_for_action()`，并在 `regional_action_ready()` 允许非遮挡 `OUTSIDE_VIEWPORT` 目标。
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentBrowserPerceptionService.java`：`browser_find` 默认（`includeHidden=false`）包含仅 `OUTSIDE_VIEWPORT` 的元素，避免长页面下方按钮/输入框/下拉框搜不到。

2. **原生 `<select>` 与点击才显示的自定义下拉框双路径闭环**
   - `apps/browser-node/crates/state-collector/src/lib.rs`：
     - 扩展交互元素采集选择器，新增 `[role="menuitemradio"]`、`[role="menuitemcheckbox"]`、`[role="listbox"]`、`[role="treeitem"]`、`[aria-haspopup]`、`[aria-expanded]`，确保 AntD / Element / Radix / Shadcn / MUI 等自定义下拉触发器与菜单项稳定投影。
     - 为非敏感 `<select>` 在 `name` 中附带前 12 个可用 `<option>` 摘要 `[options: ...]`（上限 256 字符），让 Agent 无需盲猜选项值且可直接被 `browser_find` 搜到。
     - 新增 `select_option_probe()`（支持 `NativeSelected`、`NativeOptionNotFound`、`CustomDropdown { is_text_input }`、`FallbackKeyboard`）与 `find_visible_dropdown_option()`（支持 Shadow DOM 与同源 iframe、自动在可滚动下拉列表内滚入可见项并校验 `elementFromPoint` 未遮挡）。
   - `apps/browser-node/crates/node-agent/src/main.rs`：`SELECT_OPTION` 放宽角色至 `combobox`/`listbox`/`button`/`generic`；原生 `<select>` 直接精确匹配 `value`/`text`/`label` 并派发 `input`/`change`；自定义下拉框自动先真鼠标点击触发器展开隐藏菜单 → 等待渲染 → 定位并真鼠标点击匹配选项（可搜索输入框支持自动键入过滤后再点击可见选项或回车；协议夹具保留键盘兼容回退）。

3. **直连模式完整浏览器操控（支持直连输入密码/敏感框、关闭标签页与接受弹窗，严守宿主机隔离）**
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentApplicationService.java`：新增包内入口 `createDirect()`，对直连任务保持 `FORBIDDEN_DIRECT`（shell/k8s/vault/raw CDP/关闭审计/绕过策略）严格拒绝与域名/租户/沙箱隔离不变，同时允许对敏感/密码框直连输入文本、在控制面仍以 AES-GCM 密文封存派发（明文不入数据库或普通审计）并自动授予 `allowSensitiveTarget`。
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentReviewerApplicationService.java`：保留托管模式 `reviewRoutingDecision` 对 `R2_DATA_CHANGE` 的独立模型 Reviewer 策略不变；在 `requireDirectEligible()` 放行直连完整浏览器原语（含密码/敏感输入、`CLOSE_TAB`、`ACCEPT_DIALOG`）并标记 `DIRECT_EXECUTION_AUTHORIZED`。
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentBrowserActionApplicationService.java`、`AgentExecutionService.java`、`AgentActionToolService.java`：直连模式透传 `directAuthorized` 授权（托管 `SAFE` 模式限制不变），同步支持 `OUTSIDE_VIEWPORT` 自动滚动与自定义下拉角色。
   - `apps/mcp-gateway/gateway.py` 与 `apps/mcp-gateway/README.md`：更新 `browser_find` / `browser_act` 工具说明与文档。
   - `apps/web-console/src/features/automation/AutomationPage.tsx` 与 `apps/web-console/src/types/session.ts`：直连执行控制台支持选择屏外目标（标 `↕`）、密码/敏感输入框与自定义下拉触发器。
