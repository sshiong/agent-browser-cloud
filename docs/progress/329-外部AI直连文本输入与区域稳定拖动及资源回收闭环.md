# 外部 AI 直连非敏感文本输入、区域稳定动作、MCP 精准感知、防误松拖动与资源回收闭环

2026-11-24

围绕外部 AI 与自主 Agent 顺滑连接、精准读取页面内容、在动态持续变化页面上可靠点击/输入/拖动（防思考间隔导致松开失败）以及会话创建与资源回收稳健性，完成以下五项端到端升级。

## 变更内容

1. **外部 AI 直连非敏感文本输入/选择体验（严格非敏感/非凭据围栏）**
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentReviewerApplicationService.java`：保持托管模式 `reviewRoutingDecision` 对 `R2_DATA_CHANGE` 的独立模型 Reviewer 门禁不变；在直连门禁 `requireDirectEligible()` 中新增 `isDirectPublicTextEligible()`，仅在同时满足意图 `ALLOWED`、风险 `<= R2_DATA_CHANGE`、零污点、来源受信任、`allowSensitiveTarget=false`、`dataClass` 为空或 `PUBLIC`、载荷长度 `<= 2000` 且全部动作为 `TYPE_TEXT` / `FILL` / `CLEAR_TARGET` / `SELECT_OPTION` 或既有低风险动作时放行直连。
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentBrowserActionApplicationService.java`：在入库前对每个直连动作执行目标级预检 `isDirectActionAllowed()`——仅允许可见、启用、可交互、在视口内、未被遮挡、非敏感的 `textbox` / `combobox`（`SELECT_OPTION` 仅限 `combobox`），禁止 `secretId`、禁止非 `PUBLIC` 分类，并通过 `AgentDataMinimizer.containsCredentialLikeValue()` 拦截疑似凭据/Bearer Token 明文。
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentDataMinimizer.java`：补充 `BEARER_TOKEN` 规则拦截空格分隔的 `Bearer <token>` 凭据泄露。
   - `apps/web-console/src/features/automation/AutomationPage.tsx`：直连执行控制台新增 `TYPE_TEXT`、`FILL`、`CLEAR_TARGET`、`SELECT_OPTION`（共 14 项直连动作），在直连模式强制固定 `dataClass=PUBLIC` 且隐藏 `PII/CREDENTIAL/OTP` 选择项。

2. **动态持续变化页面的区域稳定动作闭环（不伪造整页稳定）**
   - `apps/browser-node/crates/node-agent/src/main.rs`：新增 `regional_action_ready()` 与 `action_state_ready()`，在全页文档 quiet window 未成立（如长轮询/持续推流/实时行情页）但 `state.regional_stability.ready_for(&element_id)` 证明目标所在区域满足证据新鲜、已达最大等待、无进行中事务且属于稳定区域时，允许针对非敏感、未遮挡、可见目标执行动作与完成动作后稳定等待；敏感目标、未证明稳定目标或处于交易流程中的目标仍 fail-closed。

3. **MCP 感知辅助工具与页面内容准确提取**
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentBrowserPerceptionService.java`：`visibleTextSummary` 补充页面 `title` 及可见非敏感目标的值，避免大页面截断遗漏核心信息；`find()` 新增匹配非敏感输入框的当前 `value`。
   - `apps/control-plane/src/main/java/io/browsercloud/api/AgentConnectionAccessController.java`：新增 `POST /api/v1/agent-access/environments/{sessionId}/browser/find` 与 `POST /api/v1/agent-access/environments/{sessionId}/browser/inspect`（要求 `direct` 权限与连接所有权）。
   - `packages/contracts/openapi/session-api.yaml` 与 `sdks/`：同步 OpenAPI 契约至 **273 Operations / 368 Schemas**（补充 `/snapshot` 的 `agentConnectionBearer` 认证声明），重新生成并校验 TypeScript、Python、Go、Java 四语言 SDK、Manifest 与测试。
   - `apps/mcp-gateway/gateway.py`：新增 `browser_find` 与 `browser_inspect`（MCP 工具总数提升至 **16 个**），支持外部 AI 按文本/角色/标签页定向定位和精确检查元素，显著降低大页面反复全量拉取 `browser_snapshot` 的 Token 消耗。

4. **拖动增强与防 AI 思考间隔导致松开失败**
   - `apps/browser-node/crates/node-agent/src/main.rs`：
     - 将输入空闲看门狗 `INPUT_WATCHDOG_IDLE_TIMEOUT` 从 5 秒提升至 30 秒，防止跨轮次 `MOUSE_DOWN` → AI 思考/读取页面 → `DROP_TARGET`/`MOUSE_UP` 因默认 5 秒阈值被看门狗提前误释放。
     - `DRAG_TARGET` 支持两种模式：原有元素到元素/原地长按（`endTargetRef`），以及新增单次原子像素偏移拖动（`deltaX`/`deltaY`，`|delta| <= 4000`、`durationMs <= 5000`、终点非负），方便滑块与拖拽手柄一步到位不跨轮思考；拖动与滑动每步调用 `input.keep_alive()` 持续保活；`DROP_TARGET` 出错时自动 `release_all()` 防止鼠标卡住。
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentApplicationService.java`、`AgentActionToolService.java` 与 `apps/web-console/src/features/automation/AutomationPage.tsx`：同步支持 `DRAG_TARGET` 像素偏移参数校验、单目标重绑定与控制台输入。

5. **会话管理、创建与资源容量回收修复**
   - `apps/control-plane/src/main/java/io/browsercloud/application/AgentConnectionEnvironmentApplicationService.java`：只读接口（`quota`、`environment`、`environments` 以及上游 `snapshot`/`find`/`inspect`/`wait_action_task` 鉴权）改为 `@Transactional(readOnly = true)` 非锁读 `requireConnectionReadOnly()`，仅 `createEnvironment` 保留 `FOR UPDATE` 行锁，消除并发 MCP 读取串行阻塞。
   - `apps/control-plane/src/main/java/io/browsercloud/application/CoordinatorDeadlineCommandExecutor.java` 与 `SessionDeletionApplicationService.java`：在超时扫描终止/休眠会话及批量软删除会话时显式调用 `browserCapacity.release(sessionId)`，修补节点容量预留泄漏。
   - `apps/mcp-gateway/gateway.py`：`browser_create_environment` 支持可选 `display_name` 与 `agent_policy`（`BALANCED` / `INTERACTIVE`）。
