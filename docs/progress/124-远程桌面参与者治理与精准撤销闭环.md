# 远程桌面参与者治理与精准撤销闭环

> 日期：2026-08-12
> 状态：代码、正式契约和真实 PostgreSQL Integration 完成；GitHub CI 待提交后观察。

## 目标

普通 VNC 是 Agent 的协作观察/辅助通道，不创建 HumanTakeover，也不终止 Agent。运营人员
同时需要知道真实在线连接，并能只撤销一个异常连接，不能踢掉同 Session 的其他观察者、
控制者或 Agent。

## 已完成

- Control Plane 签发非敏感 `rdc_*` connectionId 并写入 HMAC Claim；票据 Nonce 仍只用于
  防重放，不进入数据库或列表 API；旧票据在 Node 由 Nonce Hash 生成兼容 ID；
- Browser Node 在真实 WebSocket 授权和断开边界发出持久 Node Event，包含 Actor、协作/
  显式接管模式、只读标志、原因和观察时间；事件经过 Node Journal、mTLS gRPC、Inbox 与
  Coordinator Term/Context Epoch 栅栏后落 PostgreSQL；
- V089 建立 `remote_desktop_participants` 权威投影、在线/时间线索引和统一 Session SSE
  Envelope。在线列表仅返回 `CONNECTED/REVOKE_REQUESTED`，不使用前端定时器或内存假数据；
- 新增真实列表 API 和管理员精准撤销 API。撤销请求写审计并经持久 Node Command Outbox
  投递；Node 只触发指定 connectionId 的 Revocation Channel，不释放其他连接、不创建排他
  Operation、不停止 Browser 或 Agent；重复撤销幂等返回当前状态；
- Web/Tauri 共用远程桌面页显示在线数、Actor、connectionId、Control/View-only、Shared/
  Exclusive 和明确文字状态；仅管理员角色显示撤销操作，统一 Session SSE 推动列表刷新；
- OpenAPI、Proto 和 TypeScript/Python/Go/Java SDK 同步为 196 个 Operation、262 个 Schema；
- Session 注销和显式 HumanTakeover 批量撤销也逐连接发终态；查询只返回当前
  contextEpoch 的在线连接，迁移或重启前的旧连接不会残留为在线；
- Safe Point 采集按 Session 使用 PostgreSQL 事务级 Advisory Lock 串行化整批信号写入，
  避免 VNC 输入与资源遥测并发更新同一组信号时丢失合法观察；Agent 详情在 VNC 窗口位于
  前台时仍继续读取权威状态；动作提交前会重新获取 Browser State，并只在同一稳定 Target
  身份、角色、名称且仍可交互/非敏感时更新 Revision，否则不提交。

## 已验证

- Rust 精准撤销测试建立两个真实 WebSocket/RFB 连接，撤销第一条后第二条仍能回显数据；
- Browser Node 14 项 Gateway 测试/Clippy、Control Plane 全量 Java 测试、Node Event Mapper
  测试、Web 70 项 API/组件测试、Lint、生产构建和 OpenAPI/Proto Lint 已通过；
- 四语言 SDK 运行时、TypeScript 发布包与多语言 Release Bundle 已通过；
- `make test-integration` 从空库顺序执行 89 个迁移，`public_tables=106`、Control Plane
  `health=UP`、双 Node/Coordinator/Storage Helper 全链通过，最终
  `node_events_inbox=71`、`node_command_published=51`、`audit_chain_valid=true`；
- 托管 E2E 已实际验证普通 VNC 保持 `RFB LIVE` 时 Agent 可执行；真人连续输入期间任务保持
  `RUNNING / HUMAN_INPUT_PRIORITY`，输入停止后同一 Operation 自动恢复并到达 `COMPLETED`；
  后续结构化动作也已成功创建和执行。完整长流程重复运行仍受既有初始 State Quality
  采集时序影响，最近一次在该前置门禁 fail-closed 为 `STATE_QUALITY_NOT_EXECUTABLE`，未为
  追求绿灯放宽安全检查；
- 完整 `make ci` 和 GitHub CI 在本轮提交前/后继续执行。
