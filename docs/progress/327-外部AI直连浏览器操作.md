# 外部 AI 直连浏览器操作

2026-11-24

外部 AI 负责读取页面、决定动作并判断是否达到任务目标。控制面收到明确动作后复用现有状态、风险、Capability、并发操作和真人输入优先规则。只有通过现有确定性低风险判定的动作才会直接派发。已有的独立结果验证仍按部署配置运行。

设置中的 Agent 连接可以显式勾选「直接操作网页」。V141 扩展可写的权限值，已有连接和未指定权限的新连接仍采用原默认值。MCP 可选部署增加四个工具：

| 工具 | 用途 |
| --- | --- |
| `browser_snapshot` | 读取连接拥有的环境的页面、元素和状态游标 |
| `browser_navigate` | 使用当前游标打开明确授权的 HTTP(S) URL |
| `browser_act` | 派发一批最多 20 个低风险动作 |
| `browser_get_action_task` | 查看同一环境的任务状态与执行结果 |

日常使用时，可在 Web 和桌面共用的「Agent 执行控制台」选择「直接执行」，也可从
运行中环境详情点「直接操作」，直接打开该环境。填写网址可以单独导航，添加动作可以
点击、长按、拖动、滑动或滚动。页面提交前读取最新快照，目标动作使用该快照的元素 ID 和版本。
如果目标变化，界面保留草稿并提示重新确认。任务结果在同一页面展示，托管模式仍为默认。

SDK 调用者可在既有 `agent-browser/act` 请求体中选择 `executionMode: DIRECT`。
导航单独提交 `navigateUrl` 和空的 `actions` 数组。导航完成后重新读取快照，再提交目标动作。
敏感输入和需要模型审核的操作继续走受控流程。直连的敏感字段在持久化计划前拒绝。控制模式、模型审查和确认要求仍由服务端策略决定。

OpenAPI 现为 271 Operations / 368 Schemas，TypeScript、Python、Go、Java SDK 同步。


验证通过：Java 全量及新增直连回归、Web 类型检查、MCP 官方客户端协议、真实
PostgreSQL 权限迁移、OpenAPI lint、四语言 SDK 和发布产物。MCP 联调通过官方客户端
→ Gateway → 控制面 → PostgreSQL / Browser Node，在 CDP 夹具中完成快照、悬停与结果读取，
并验证缺少直连权限及跨连接访问均被拒绝。测试容器和本轮专用镜像已清理。
Oracle 实际部署与真实 Chromium 的新直连路径仍待验收。


普通控制台的 Chrome 浏览器测试使用明确的 API 夹具，覆盖模式切换、预选环境、
导航请求、点击的元素绑定、即时结果显示，以及过期游标后的重试。Web 构建、类型与测试通过。


直连的通用页面手势沿用现有动作批次。长按复用同一目标的 `DRAG_TARGET`，
Browser Node 按住后在原位置等待指定时长再松开。拖动绑定起点和终点，滑动绑定起点和像素位移。
Web 和桌面直接提交这些动作，外部 AI 可通过现有 MCP `browser_act` 提交同样的参数。
OpenAPI 和数据库版本保持当前基线。

Chrome 界面回归覆盖三种手势的参数和目标绑定。MCP 联调在 CDP 夹具中经正式 Gateway、
控制面、PostgreSQL 和 Browser Node 顺序完成长按、拖动、滑动，三个动作均返回 SUCCEEDED。
Browser Node 测试 35 项通过、1 项忽略。Oracle 上的新手势仍待实机验收。
