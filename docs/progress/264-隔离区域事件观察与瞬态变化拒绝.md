## 实现

连续完整采样可能看不到“两次采样之间改变后恢复”的 DOM 属性变化。
Node 现在在精确主 Frame 中创建固定名称的隔离 JavaScript World，前后读取受信
Frame/Loader 并与完整快照比对，显式 `grantUniveralAccess=false`，不读取跨域 Frame。
私有观察器最多监控四十个当前路径；MutationObserver、输入/焦点/滚动/CSS 动画事件与
ResizeObserver 形成有限序号。新的观察器代次、DOM 元素实例、区域事件序号或当前活动
动画都会使目标窗口重建。最近业务实体容器及 stylesheet DOM 变化也会使窗口失效。

观察器不读取输入值、Secret 或业务实体正文；Nonce、原始路径、事件序号只在 Node
内存中使用，不进入 API、Protobuf、数据库或常规 Audit。页面主上下文不能供给私有
证据，反序列化明确跳过这些字段。未获观察证明、Shadow Root/子 Frame、不完整、
异常序号、重复身份、超过预算或文档变化时 fail-closed；普通动作门禁保持现有授权逻辑。
一次额外 CDP 观察共用三秒截止时间，无候选路径时不给证明并跳过连接。

## 剩余边界

这里不宣称观察到了全部瞬态视觉/脚本状态：CSSOM 直接修改、无事件的属性值恢复、
Canvas/媒体、子 Frame 与 Shadow Root 的连续观察仍需补充或明确拒绝。
已观察的当前动画可拒绝，但不把所有已结束的 Web Animation 当作完整历史证据。
完整 V16 Event Watermarks、可信低风险/Capability 授权、执行前围栏、区域有界动作与
独立业务 Outcome 仍未闭环。公开连续十七例与真实客户/供应商、目标环境、组织及
许可证 Gate 保留，整体目标继续 active。
