# 剩余缺口、Gate 与实施顺序

## 生产阻塞项

| ID | 缺口 | 验收标准 |
|---|---|---|
| SEC-001 | REST API 没有真实 Bearer/OIDC，`X-Tenant-Id` 只是开发防误读 | Tenant 必须从已认证 Principal 派生，并完成 OIDC、RBAC 与权限测试 |
| SEC-002 | CP↔Node gRPC 明文且没有节点身份校验 | mTLS、节点证书轮换和授权策略通过验收 |
| REL-001 | Node Dedup/Term 只在内存 | SQLite Journal 重启后仍去重并拒绝旧 Term |
| REL-002 | Node Runtime Event 未回传 | 命令、事件、状态提交与 Operation 完成形成闭环 |
| REL-003 | Domain Outbox 没有消息总线 Publisher/Inbox Consumer | At-least-once、消费去重、重放和 DLQ 演练通过 |
| RUN-001 | 真实 Chromium/CDP/Crash Recovery 未实现 | 真实 Chromium 启动、探针、崩溃恢复和资源上限测试通过 |
| RUN-002 | noVNC/Input Broker/State Collector 为骨架 | HumanTakeover 与 State Resync 用例通过 |
| GOV-001 | 审计保留、Legal Hold 与删除证明未闭环 | V16 治理和生产运营 Gate 通过 |

2. 完成 Node Runtime Event 回传，使 Start/Terminate Operation 能进入终态。
3. 实现统一 SSE/WebSocket 层，并替换详情页轮询。
4. 接入 OIDC、Principal Tenant 与 RBAC `<Can>` 组件。
5. 生成 OpenAPI TypeScript Client，并迁移当前手写 Session Client。
6. 按 Runtime → Profile → Proxy → Browser Node 的顺序替换 Fixture。
7. 接入 Logs、Security、Audit，并确保后端先脱敏。
8. 完善创建九步向导、远程桌面、HumanTakeover 和恢复流程。
9. 增加 1280×800、1440×900、1920×1080 的视觉回归与键盘可访问性测试。
