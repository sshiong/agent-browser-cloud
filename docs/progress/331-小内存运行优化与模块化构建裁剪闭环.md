# 小内存运行优化与模块化按需构建闭环

2026-11-24

针对 2–4 GB 小内存机器的运行时开销优化，以及构建/启动阶段按需选择开放模块（MCP、Web 控制台、VNC 远程桌面、录制脱敏扫描器、4 个托管模型 Worker、小内存调优层）的需求，补齐镜像参数化裁剪、运行时内存压降与模块化 Compose 入口。

## 变更内容

1. **Browser Node 构建裁剪与低内存 Chromium 运行模式**
   - `apps/browser-node/Dockerfile`：新增构建参数 `ENABLE_REMOTE_DESKTOP`（默认 `true`）与 `ENABLE_RECORDING_SCANNER`（默认 `true`）；关闭 `ENABLE_REMOTE_DESKTOP=false` 时跳过安装 `xvfb`/`x11vnc`，关闭 `ENABLE_RECORDING_SCANNER=false` 时跳过安装 OpenCV + Tesseract OCR（镜像体积直降约 700 MB 并显著提速构建）。默认构建行为不变。
   - `apps/browser-node/crates/node-agent/src/main.rs`：允许通过将 `XVFB_PATH` / `X11VNC_PATH` 置为空串在运行时直接关闭 VNC 桌面，无需重新编译。
   - `apps/browser-node/crates/runtime-supervisor/src/lib.rs`：新增 opt-in 环境变量 `BROWSER_LOW_MEMORY_MODE=true`，在保持 Chromium 沙箱完整不变的前提下追加 `--disable-dev-shm-usage`、`--renderer-process-limit=2`、`--disk-cache-size=33554432` 与 `--js-flags=--max-old-space-size=256`，防止小内存容器下 `/dev/shm` 或渲染进程膨胀导致 OOM。

2. **Control Plane 可配内存与连接/线程池上限**
   - `apps/control-plane/docker-entrypoint.sh`：支持读取 `JAVA_OPTS`（未设置时保持原有 `-XX:MaxRAMPercentage=75` 默认行为）。
   - `apps/control-plane/src/main/resources/application.yml`：开放 `SERVER_TOMCAT_THREADS_MAX`（默认 200）、`SERVER_TOMCAT_THREADS_MIN_SPARE`（默认 10）、`DATABASE_POOL_MAX_SIZE`（默认 10）与 `DATABASE_POOL_MIN_IDLE`（默认 2），默认行为不变，小内存叠加层可按需收紧。

3. **模块化 Compose + 小内存叠加层 + 构建/启动选择器**
   - `deploy/compose/modular.yml`：核心栈（`postgres`、`redis`、`control-plane`、`browser-node`、`storage-helper`）独立常驻，将 `mcp-gateway`（`mcp`）、`web-console`（`web`）与 4 个托管模型 Worker（`workers`）拆分为独立 Profile；未启用 `workers` 时自动关闭 Control Plane 外部 Worker/Reviewer/Outcome 队列，直连模式免外部模型 Key 即可启动。
   - `deploy/compose/low-memory.yml`：面向 2–4 GB 机器的调优叠加层——Control Plane 切至 SerialGC + `-Xms96m -Xmx288m -XX:MaxMetaspaceSize=160m`（448M 上限、5 DB 连接、24 Tomcat 线程）、PostgreSQL `shared_buffers=32MB`（192M 上限）、Redis 48M `allkeys-lru`（64M 上限）、Browser Node 开启 `BROWSER_LOW_MEMORY_MODE=true` + 1536M 认证/容器上限 + 默认 2 并发会话与 1280×720 VNC，将空载常驻内存压低至约 450–650 MiB。
   - `tools/local-dev/stack.sh`、`deploy/compose/README.md` 与 `Makefile`（`stack-config`/`stack-build`/`stack-up`/`stack-down`/`stack-ps`）：支持三种预设（`minimal-mcp`、`direct-lite`、`full`）、任意单开关组合（`--mcp/--no-mcp`、`--web/--no-web`、`--workers/--no-workers`、`--vnc/--no-vnc`、`--recording/--no-recording`、`--low-memory/--no-low-memory`、`--max-sessions`、`--node-mem-mb`、`--bind-host`）以及 `--interactive` 交互式勾选。原根目录 `docker-compose.yml` 保持不变。
